# Interactive Confession Web Page (Open This Web)

Proyek web interaktif sederhana yang dirancang untuk menyampaikan pesan atau perasaan secara elegan, modern, dan berkesan. Halaman web ini menggunakan antarmuka berbasis kartu (*card interface*) yang responsif dengan efek visual yang menawan.

---

## ✨ Fitur Utama

- **Tampilan Visual Modern**: Menggunakan kombinasi warna pastel manis, efek *glassmorphism*, dan bayangan lembut.
- **Transisi Halaman Mulus**: Perpindahan antarhalaman menggunakan animasi *fade-in* dan *slide* yang alami.
- **Elemen Interaktif**:
  - Tombol dengan efek *glossy shimmer* (kilauan) serta animasi *bounce* saat ditekan.
  - Emoji bunga interaktif dengan animasi melayang (*floating animation*).
  - Integrasi tautan langsung ke WhatsApp.
- **Responsif**: Tampil sempurna di perangkat *mobile* (smartphone) maupun *desktop*.
- **Tanpa Dependency Luar**: Dibuat murni dengan HTML5, CSS3, dan Vanilla JavaScript tanpa pustaka (*library*) eksternal.
